## English

### Summary
- The app does **not** collect personal data.
- There is **no** analytics, tracking, telemetry or advertising.
- There is **no** account or sign-in.
- All your data (servers, settings, logs, downloaded Java) is stored **on your own computer**.

### Network connections the app makes
The app only talks to the services below, and only to do what you asked for.

| Service | Hosts | Purpose |
|---|---|---|
| GitHub | raw.githubusercontent.com, api.github.com, github.com | App updates, the data file (`data.json`) and language files |
| Mojang | piston-meta.mojang.com, piston-data.mojang.com | Vanilla version list and server downloads |
| PaperMC | fill.papermc.io | Paper, Folia and Velocity downloads |
| Purpur | api.purpurmc.org | Purpur downloads |
| Leaf | api.leafmc.one | Leaf downloads |
| Fabric | meta.fabricmc.net | Fabric version list and server downloads |
| Modrinth | api.modrinth.com, cdn.modrinth.com | Searching and downloading plugins and mods |
| Adoptium | api.adoptium.net | Downloading Java |
| playit.gg | playit.gg and its tunnel servers | Only when you turn it on: lets friends join through a public address |

Like any internet request, these services can see your IP address and the app's User-Agent string. Their own privacy policies apply to what they do with it.

### Minecraft EULA
Before a server can run, you must accept the Minecraft EULA. The app opens the EULA in your web browser so you can read it. The app does not accept it for you.

### Your data
Everything stays on your computer. Uninstalling the app does not delete your servers unless you tick the option to delete all data.

## Tiếng Việt

### Tóm tắt
- Ứng dụng **không** thu thập dữ liệu cá nhân.
- **Không** phân tích, theo dõi, gửi số liệu sử dụng hay quảng cáo.
- **Không** cần tài khoản hay đăng nhập.
- Mọi dữ liệu của bạn (server, cài đặt, nhật ký, bản Java đã tải) được lưu **ngay trên máy của bạn**.

### Các kết nối mạng mà ứng dụng thực hiện
Ứng dụng chỉ kết nối tới các dịch vụ dưới đây, và chỉ để làm việc bạn yêu cầu.

| Dịch vụ | Địa chỉ | Mục đích |
|---|---|---|
| GitHub | raw.githubusercontent.com, api.github.com, github.com | Cập nhật ứng dụng, tệp dữ liệu (`data.json`) và tệp ngôn ngữ |
| Mojang | piston-meta.mojang.com, piston-data.mojang.com | Danh sách phiên bản Vanilla và tải server |
| PaperMC | fill.papermc.io | Tải Paper, Folia và Velocity |
| Purpur | api.purpurmc.org | Tải Purpur |
| Leaf | api.leafmc.one | Tải Leaf |
| Fabric | meta.fabricmc.net | Danh sách phiên bản và tải server Fabric |
| Modrinth | api.modrinth.com, cdn.modrinth.com | Tìm kiếm và tải plugin, mod |
| Adoptium | api.adoptium.net | Tải Java |
| playit.gg | playit.gg và các máy chủ đường hầm của họ | Chỉ khi bạn bật: cho bạn bè vào server qua địa chỉ công khai |

Như mọi yêu cầu qua internet, các dịch vụ này có thể thấy địa chỉ IP của bạn và chuỗi User-Agent của ứng dụng. Chính sách riêng tư của từng dịch vụ quy định cách họ dùng thông tin đó.

Server chỉ chạy được sau khi bạn chấp nhận Minecraft EULA. Ứng dụng mở EULA trong trình duyệt để bạn đọc, và không tự chấp nhận thay bạn.

### Dữ liệu của bạn
Mọi thứ nằm trên máy của bạn. Gỡ cài đặt ứng dụng không xóa server của bạn, trừ khi bạn tích chọn xóa toàn bộ dữ liệu.
